# Weight-editing experiment audits

- Classify the artifact and each experiment separately: reading raw weights, writing a policy with supplied source/rules, editing after a failed trajectory, and editing with practice inference have different evidence access. No gradient descent does not imply no data, no answers, no activation access, or no behavioral feedback.
- Distinguish disabled native agent tools from author-run sandbox code. A `tool_free` event audit can coexist with extensive Python execution and batched forward tools. Report what a pass can contain, total turns/code runs, and wall-time exclusions before implying optimization cost.
- Read the final submission report, diff manifest and first task prompt. Record layer numbering, tensor identity, selection criterion, layer-specific direction, intervention coefficient, and whether a sparse edit reverses/amplifies a direction rather than merely projecting it out. Separate touched values from values that differ after deployment-dtype rounding; sparse edits need not be small in norm.
- Keep edit-selection practice sets, internally held-out practice confirmation, final benchmark tests and pretraining contamination as separate questions. Author-declared test isolation is not a proof against all contamination.
- Inspect the scorer and aggregation: sample-average accuracy is not pass@n; length-limit termination is not a direct loop detector. Compare strict-boxed and format-agnostic answer extraction, prompt-level versus instruction-level compliance, sampling, thinking mode and token limits before comparing models or negative controls.
- Preserve negative and incomplete runs. Chance-level/tie answers and an interrupted fourth attempt are not four completed zero-accuracy evaluations. Attention-assisted classification is not weight-only auditing, and a loop-removal gain does not establish arbitrary new capability injection.
- Reconcile live figures with completed evaluation JSON. A partial denominator or stale chart can differ from final merged results. For republished checkpoints, separate the original score from a later rerun; a full edited-model evaluation plus a small base smoke test is not a full paired rerun. Aggregate public correct arrays locally when available, without implying inference was reproduced.
- Pin log and model revisions independently. Separate text-only evaluated exports from full multimodal releases, metadata/manifest hash agreement from hashing downloaded tensors, and public final diffs from omitted intermediate activations, harness servers, checkpoints or previous prompt trials. Read licenses per artifact and preserve upstream dataset/source terms.
