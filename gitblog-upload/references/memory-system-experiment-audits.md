# Memory-system experiment audits

Use for agent memory, raw-history RAG, memory compression and dynamic-state evaluation posts.

- Separate offline historical question answering from operational memory requirements. Correctly withholding a deleted value in an answer does not demonstrate physical erasure from raw logs, indexes, caches or backups, nor authoritative state for tools and actions.
- State the ranking denominator and excluded references. Recompute claimed wins from the actual table; keep Full-context and supplementary personalization results visible rather than extending a main-suite headline to every task.
- Separate direct reruns from published baseline scores and matched comparison blocks. Preserve reader, retriever/reranker, judge repetition, question subset, profile setting and software version. A summary table need not be a single controlled rerun.
- Preserve native aggregation. Conversation QA may be question-weighted, dynamic-memory benchmarks task-macro averaged, and capability suites hierarchically weighted across sources. Do not call every percentage binary accuracy or pool all questions.
- Distinguish retrieval item count from actual reader tokens. Window overlap, whole-turn display expansion, headers and duplicated turns change evidence volume. Describe cross-system caps separately from RAG-only budget sensitivity; historical hosted configurations and clipped prefixes are not retuned equal-budget systems.
- Audit coverage and utilization independently of final score. Check semantic LLM judgments versus deterministic answer-value proxies, result coverage versus path given result, and after-state/before-pass filters. Conditional utilization uses system-specific covered cohorts and does not isolate reader skill; do not multiply it by coverage to reconstruct a differently aggregated benchmark total.
- Identify gold-informed selection and task-aware readout in every oracle. Report phase-visible snapshots, support-session selection, packing caps, gold locations/values and policy supplied to the reader. Native-to-oracle improvement is not a pure retrieval intervention when readout instructions also change, and residual gaps are not pure information-loss measurements.
- Keep representation effects qualified. Atomic extraction can change evidence volume, demonstration boundaries, input-label pairings and reader format as well as factual content; one ablation cannot distinguish these causes without controls.
- Bound latency claims by workload, readiness barrier, outer and internal concurrency, hardware, endpoints and timed stages. Add plus Search excluding reader generation is not end-to-end answer latency, free inference or a universal throughput guarantee.
- Inspect the current pinned official source tree and evaluation profiles before describing implementation availability. Historical issue comments that code was missing can become stale. Record static inspection separately from running paid model APIs or reproducing the benchmark.
