# Native VLA evidence and release checks

- Interpret encoder-free structurally: a convolutional patch embedder and a multimodally pretrained backbone still perform visual learning. Do not call the policy trained from scratch merely because it lacks an external vision tower.
- Separate backbone size from the added action expert. Compare matched backbone/expert depth before attributing gains to readout location; early-only maps may also truncate the backbone and change compute. Keep intermediate-feature access ablations separate from pure encoder-removal causal claims because backbone pretraining and capacity can differ.
- Distinguish controlled action-pretraining experiments from final benchmark recipes, checkpoints and episode counts. Inspect task-weighted totals, visual-versus-position/goal perturbations, and real-robot ID/OOD aggregation instead of flattening them into general robustness.
- Report raw action-chunk length, Euler/denoising steps, device, precision, compilation and request/IK boundaries with latency. Faster sampling does not inherit success rates measured with more steps, and chunk-generation latency is not the controller's per-step frequency. Mark sped-up demonstration videos as qualitative evidence.
- Read current raw model cards and file trees, not cached page extraction alone. New task-specific checkpoints and backbone exports may appear after an initial stage1/stage2 release. Distinguish a post-trained backbone with its action expert removed from the original initialization checkpoint and from an executable robot policy; preserve checkpoint-specific normalization records.
- Separate intended training-corpus inventory from upload completion. Verify trajectory, companion metadata and camera parts per usable entry. A mixed-embodiment viewer schema failure does not itself prove custom training ingestion fails; report the scope actually checked.
- Compare released co-training defaults with the paper's original understanding-data mixture and optimizer-step cadence. Treat a convenient example dataset as an example, not full original reproduction; keep upstream model/data terms separate from the code license.
